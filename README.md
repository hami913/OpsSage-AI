# OpsSage AI

Agentic AI Incident Detection and Root Cause Analysis Platform.

## Overview
OpsSage AI is an intelligent platform designed to detect unusual server activity, investigate incidents, identify possible root causes, and recommend evidence-based solutions.

## Core Components
- Machine Learning Anomaly Detection
- RAG Knowledge Retrieval
- Agentic AI Investigation
- Root Cause Analysis
- FastAPI Backend
- Streamlit Dashboard

## Technology Stack
Python, Scikit-learn, FastAPI, Streamlit, Qdrant, PostgreSQL, Docker and MLflow.

## Project Status
Phases 1–10D completed; Phase 10E (Agentic AI RCA) in progress.

## Disclaimer
This project is currently under development.
